## Data Safety (Google Play)

Declarar en Play Console > App content > Data safety:

| Pregunta | Respuesta |
|----------|-----------|
| Does your app collect or share any of the required user data types? | **No** (toda la data se guarda local, sin backend) |
| Is all of the user data collected by your app encrypted in transit? | N/A (no transit) |
| Do you provide a way for users to request their data be deleted? | Yes (uninstall borra toda la data) |

**Optional sharing:**
- Crashlytics: Crash logs (anonymous, no user ID linked)
- Analytics: Anonymous app interaction events (no PII)

Marcar como **opcional** y **anonymous**, sin link a identidad.
